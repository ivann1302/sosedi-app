# Правила публикации объявления

- Версия: `2026-07-28`
- Статус: действует для создания новых объявлений
- Способ принятия: `ITEM_CREATE_FORM`

Перед отправкой объявления на модерацию пользователь отдельно подтверждает, что:

1. вправе распоряжаться вещью и передавать её во временное пользование;
2. проверил исправность вещи и корректно указал её состояние;
3. полностью и точно указал передаваемую комплектацию;
4. прочитал предупреждение выбранной категории и соблюдает применимые правила
   безопасности и площадки, включая запрет на запрещённые и ограниченные вещи.

Backend принимает только все четыре явных подтверждения и точное значение текущей
версии. Вместе с Item он сохраняет `ownerId`, server timestamp, способ принятия,
версию этого документа и snapshot категорийного `safetyNotice`. Историческим
объявлениям эти значения задним числом не назначаются.

Этот технический документ фиксирует содержание подтверждения при создании
объявления, но не заменяет публичную оферту/rental rules и не закрывает остальные
пункты marketplace legal/safety gate из `MVP_CHECKLIST.md`.
