## Исправления

1. Повтор загрузки фото после частичного успеха начинался с первого файла.
   Потеря ответа confirm при двух фото воспроизводилась как четыре разных
   подтверждённых intent. Теперь controller хранит прогресс только в памяти
   текущей публикации: завершённые фото пропускаются, неизвестный результат
   подтверждения повторяется с прежним intent. Backend уже возвращает результат
   повторного подтверждения того же intent без создания второго фото.
2. Явный HTTP 400 `VALIDATION_ERROR` при подтверждении (включая истечение intent)
   позволяет повторить загрузку незавершённого фото; неоднозначная сетевая ошибка
   сохраняет intent. Оба случая воспроизведены падающими тестами до исправления.
3. iOS smoke искал английский tooltip `Back` после русификации приложения.
   Теперь тест нажимает настоящий `BackButton`, независимо от языка tooltip.
4. На компактном экране iPhone 7 новое сообщение сохранялось, но оставалось вне
   видимой части списка. Чат теперь после успешной отправки прокручивается к
   последнему сообщению; регрессия покрыта widget-тестом 375×667 и физическим
   integration smoke.
