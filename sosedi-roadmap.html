Правила работы Codex с roadmap
Перед задачей выбрать первый пункт со статусом TODO в текущей фазе и отметить его DOING.
После реализации и проверки изменить статус пункта на DONE и обновить процент прогресса фазы.
Если пункт нельзя завершить без внешних данных, отметить BLOCKED и кратко записать причину в ответе.
В финальном ответе всегда назвать следующий рекомендуемый пункт roadmap.
Как считать прогресс
Считать только пункты с атрибутом data-status.
Формула: DONE / все roadmap-пункты текущей фазы × 100.
Не считать критерии успеха, запреты и post-MVP идеи как выполненные задачи MVP 0.1.
Статусы: TODO, DOING, DONE, BLOCKED.

Roadmap

Поэтапный план разработки от Foundation до MVP 1.0. Каждая фаза имеет чёткий критерий успеха.

1
MVP 0.1 — Marketplace Foundation ⏱ 4–6 недель Старт
Backend (NestJS)
Prisma schema + начальная миграция + seed категорий
Авторизация по SMS (OTP + JWT refresh)
Пользователи, роли (арендатор / арендодатель / admin)
Категории инструментов
CRUD объявлений + загрузка фото (S3)
Геопоиск: PostGIS ST_DWithin + индексы
Фильтрация: категория, цена, радиус, доступность
Модерация объявлений (статус pending/approved/rejected)
Admin panel: модерация объявлений и управление пользователями
Mobile (Flutter)
Онбординг (3 слайда) + SMS-логин
Mobile Map: Yandex MapKit + геолокация + маркеры + радиус
Mobile Catalog: список объявлений + поиск + фильтры
Tool Details: фото, цена, локация, владелец
Profile + My Tools: профиль + мои объявления
Create Tool + photo upload: форма объявления + presigned URL
Критерий успеха
Первые арендодатели публикуют объявления
2
MVP 0.2 — Первая аренда ⏱ 2–3 недели Бронирование
Добавить
FSM бронирования: PENDING → CONFIRMED → PAID → ACTIVE → RETURNED → COMPLETED
Календарь доступности инструмента
Единый список статусов: PENDING, CONFIRMED, PAID, ACTIVE, RETURNED, COMPLETED, CANCELLED, DISPUTED
История заказов (арендатор и арендодатель)
FCM — фоновые push-уведомления: новая заявка, подтверждение, отмена
WebSocket Gateway — события в активной сессии приложения
Критерий:Первая аренда состоялась без онлайн-оплаты: ручная/офлайн оплата

Анализ и улучшения

Технический анализ архитектуры, выявленные риски и конкретные рекомендации по оптимизации.

Закрытые риски

✅

Prisma schema и миграции готовы

schema.prisma, первая миграция и seed категорий уже есть. Продолжать менять структуру данных только через Prisma Migrate.

Закрыто
✅

PostGIS GiST index добавлен

tools.location хранится как geography point, обновляется trigger-ом и индексируется через tools_location_idx. Радиус геопоиска ограничен 50 км.

Закрыто
✅

SMS rate limit включён

OTP flow уже хранит счётчики в Redis: 3 кода за 10 минут, 5 неверных попыток и блокировка на 30 минут.

Закрыто
✅

Photo pipeline готов

Upload работает через presigned URL, BullMQ обрабатывает изображения и хранит original, thumbnail и preview.

Закрыто
✅

API namespace закреплён

Backend и mobile используют /api/v1/. При изменении endpoint-ов обновлять DTO, Swagger/OpenAPI и документацию в той же задаче.

Закрыто
✅

Admin audit log реализован

AdminAuditLog уже фиксирует действия администратора. Для новых admin-функций добавлять запись аудита сразу в рамках задачи.

Закрыто

Критические риски

🔥

Mobile Map зависит от ключа и permissions

Следующий roadmap-пункт требует Yandex MapKit key и платформенных разрешений Android/iOS. Ключ хранить только через env/dart-define, без hardcoded secrets.

Критично
🔥

Backend готов быстрее mobile-витрины

Категории, объявления, upload и модерация уже есть на backend, но пользователь ещё не видит полный сценарий: карта, каталог, карточка и создание объявления.

Высокий
⚠️

Booking FSM нужно закрепить до этапа 0.2

Перед backend booking реализовать простую enum-based FSM в NestJS. Не добавлять XState: для MVP достаточно явной карты разрешённых переходов.

Высокий

Оставшиеся архитектурные улучшения

🔍

Full-text поиск через PostgreSQL FTS

Для Mobile Catalog достаточно PostgreSQL tsvector + GIN вместо Elasticsearch. Добавлять вместе с текстовым поиском, без отдельного search-сервиса.

Оптимизация
🛡️

Антивирусная проверка фото

MIME-type, лимит размера и presigned upload уже закрыты. ClamAV или другой scanner добавить позже, если появится реальный риск abuse.
